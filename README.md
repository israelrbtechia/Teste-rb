# Reparo Simples · Landing page

Página de vendas do Reparo Simples (sistema para assistência técnica de celulares).

- `index.html`: a página inteira em um arquivo (imagens e vídeo do app embutidos).
- Links de checkout da Kiwify e preços: no fim do `index.html`, bloco **EDITE AQUI**.
- `sw.js`: desliga o cache do app de teste que existia antes neste endereço.

As telas e o vídeo são do app real, gravados com uma loja e clientes fictícios.
